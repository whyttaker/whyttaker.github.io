Retro Racer

Retrowave multiplayer racing game — Unity & C#

Overview

About the Project

Retro Racer is a retrowave-themed multiplayer racing game that draws inspiration from classic racing titles and repackages them in a vibrant, neon-soaked aesthetic. Built for a multiplayer games systems class at UC Irvine, I led a team of four through the full lifecycle — from initial concept to playable build.

Development

Learning Unity

This was my first time using Unity or any game engine beyond tutorial projects. It was also my first real experience using GitHub for multi-person version control — once the workflow was established, it became the backbone of how we shipped changes and avoided stepping on each other's work.

Process

The Design Process

We drew heavy inspiration from existing racing games and spent time brainstorming on whiteboards and in notebooks to nail down the core vision. That upfront planning gave the team a clear roadmap and made execution significantly more manageable as the project grew in complexity.

Takeaways

What I Learned

This project taught me a lot about managing a development team under real constraints — balancing workloads, maintaining momentum, and making design decisions under uncertainty. Working hands-on with Unity alongside GitHub for version control gave me a strong foundation in both game development and collaborative software engineering workflows.
