Quantum Leap

Puzzle platformer with time manipulation — Unreal Engine & C++

Overview

About the Project

Quantum Leap is a puzzle platformer built around a time manipulation mechanic that allows players to interact with past versions of themselves to solve puzzles. The project explores deterministic replay systems that enable multiple timelines of player actions to coexist and interact within the same environment.

Design Process

Design & Iteration

The game was designed around cooperative problem solving across time. Early levels introduce the time manipulation mechanic through simple puzzles before combining it with environmental interactions such as switches, platforms, and timing-based triggers. This progression allowed players to understand the mechanic before encountering more complex multi-step puzzles.

Implementation

Technical Architecture

The core system records player inputs and interactions over time and replays them as ghost entities in future iterations. Player movement, input states, and object interactions are captured in time-indexed structures and reconstructed during replay sequences. The system allows the current player to interact with previously recorded actions, enabling puzzles that require coordination across multiple timelines.

Algorithms & Data Structures

Systems Design

The replay system stores time-indexed player states in sequential data structures that allow deterministic reconstruction of past actions. Event-driven architecture is used to trigger puzzle interactions and environmental state changes. Fixed update intervals are used to maintain synchronization between recorded player actions and world simulation.

Key Engineering Challenges

What Was Hard

Ensuring deterministic replay across multiple timelines was the primary challenge. Physics interactions and environmental triggers needed to behave consistently across replay cycles so that puzzle outcomes remained predictable. Managing interactions between multiple versions of the player also required careful control of collision detection and event ordering.

Takeaways

What I Learned

This project helped me develop systems centered around a single core mechanic while managing complex state across time-based simulations. I gained experience designing deterministic replay systems, implementing event-driven puzzle interactions, and structuring gameplay architecture to support scalable mechanics.
